# pH7Software

Open-source software for independently owned dating websites, matchmaking services and online communities.

Our main project is **[pH7Builder](https://ph7builder.com/)** (formerly pH7CMS), a self-hosted PHP application created by [Pierre-Henry Soria](https://github.com/pH-7). It includes foundations for member profiles, discovery and matching, messaging, memberships, moderation and administration. Features depend on the modules and services you configure.

You can inspect and customise the source, choose your own hosting and keep control of your code and member data. The pH7Builder core is licensed under **[MIT](https://github.com/pH7Software/pH7-Social-Dating-CMS/blob/18.x/LICENSE.md)**.

## Get started

- **[pH7Builder website](https://ph7builder.com/):** Understand the software and its use cases.
- **[Free blueprint generator](https://ph7builder.com/build/):** Describe your dating or community product and download a portable YAML blueprint and coding-agent prompt. The tool does not deploy an application.
- **[Get pH7Builder](https://ph7builder.com/get-started/):** Installation options and requirements.
- **[Source code](https://github.com/pH7Software/pH7-Social-Dating-CMS):** Explore the application and contribute.
- **[Published releases](https://github.com/pH7Software/pH7-Social-Dating-CMS/releases):** Download a supported release rather than an unreleased development branch.
- **[Installation and upgrade guides](https://github.com/pH7Software/pH7-Social-Dating-CMS/tree/18.x/docs):** Use the documentation matching your release.

## Contribute

Before changing the core, read its [contribution guide](https://github.com/pH7Software/pH7-Social-Dating-CMS/blob/18.x/CONTRIBUTING.md) and [AGENTS.md](https://github.com/pH7Software/pH7-Social-Dating-CMS/blob/18.x/AGENTS.md). Use [GitHub Discussions](https://github.com/pH7Software/pH7-Social-Dating-CMS/discussions) for ideas and setup questions, and [Issues](https://github.com/pH7Software/pH7-Social-Dating-CMS/issues) for reproducible bugs.

The goal is practical software that developers and AI coding agents can understand, extend and maintain without locking operators into a proprietary platform.
